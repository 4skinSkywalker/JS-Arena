# JS Arena

> Master JavaScript, PostgreSQL, and CSS through coding challenges.

Play JS Arena directly in your browser:
👉 [https://js-arena.dev/](https://js-arena.dev/)

JS Arena is a coding site where developers sharpen their skills by solving challenges in JavaScript, PostgreSQL, and CSS, whether you prefer practicing solo or competing against your friends/colleagues.

## Features

* 🎮 **Arcade Mode** — Solve coding challenges at your own pace.
* ⚔️ **Online Multiplayer** — Challenge other players in real-time coding matches.

## Supported Languages

* JavaScript
* PostgreSQL
* CSS

More languages may be added in the future.
